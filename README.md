# makefun-crypto-trading-joke

A program that writes one original crypto trading joke to `/output/entry.txt` — the
whole entry for the make.fun competition **"Laugh Track: The Crypto Trading Joke Contest"**
(`u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a`).

## The joke

> My trading strategy is simple: buy the top, panic-sell the bottom, then tell my group chat it was a long-term plan all along.

125 characters. A true trading-life observation (buy high, sell low, then
rebrand the loss) with the turn saved for the last words: the group chat is
where every bad trade retroactively becomes a plan. No pun, no stock line —
the surprise is the rebranding, and it reads cleanly aloud in one breath.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
